# Cesium LOD (Level Of Detail) demo
Just a slider on a CesiumJS wrapper that show what exactly is LOD in 3D Tileset rendering.

The tileset's LOD is computed based on a screen space error. More of this concept and how it's used [here](https://github.com/marianguceanu/Notes/blob/master/Presentations/Real%20Time%203D%20Geospatial%20Visualization.md#3-how-does-cesium-do-it).
